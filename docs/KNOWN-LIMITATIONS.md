# 已知限制

> 本文件如实列出**当前版本做不到的事**。写在这里是为了让预期清楚，而不是藏着。

---

## 一、发行与签名

| 限制 | 说明 | 计划 |
|---|---|---|
| **未签名**（若当前发布版为未签名） | macOS 会提示「来自身份不明的开发者」；Windows 会出 SmartScreen 提示 | 需要开发者证书 |
| 无自动更新 | 本期关闭自动更新（不指向官方更新源），升级需手动下载新版本 | 评估社区更新源 |
| 手动分发 | 没有应用商店，从社区发布页 / 网盘获取 | |

**未签名版本的安装方法**见 [README](../README.md#下载与安装)。

---

## 二、平台

| 限制 | 说明 |
|---|---|
| 不支持 Linux | 宿主（DSH Desktop）的目标校验会拒绝非 macOS/Windows 平台 |
| 不支持手机 / 平板 | 不在本期范围 |
| 不支持浏览器直接使用 | 是桌面应用，不是 Web 应用 |

---

## 三、功能边界（刻意的）

这些不是「没做完」，而是**产品设计上不做**：

| 不做 | 原因 |
|---|---|
| 不做诊断 / 处方 / 剂量 | 医疗红线（见 [医疗免责声明](MEDICAL-DISCLAIMER.md)） |
| 不解读量表得分 | 红线 M-3 |
| 不做入组资格判定 | 只做「逐条对照 + 溯源」 |
| 不做试验推荐排序 | 隐含资格判定 |
| 不做自动提醒推送 | 一期不做（不催你） |
| 不做云同步 / 账号 | 数据主权优先 |
| 不做第三方云盘集成 | 不把病历交给不可控第三方 |
| 不做营养处方 / 食谱 / 食物库 | 越界 |
| 不做药物相关内容 | 红线 M-2 |
| 不做影像（CT/MRI）图像分析 | 只提取影像报告的文字结论 |
| 不做分子分型的临床解读 | 只做名词科普 |

## 四、功能完成度（本期未实现）

| 未实现 | 计划 |
|---|---|
| **一键备份 / 还原** | （当前可手动复制数据目录；**数据自检**已能验证备份可读性） |
| **MinerU 云端解析的完整接入** | （当前只有开关与隐私闸门，未接真实服务） |
| **临床匹配的完整规则引擎** | （当前「入组档案」可完整录入；试验检索 / 逐条对照 / 收藏为后续版本） |
| **营养管理完整实现** | （当前可记录体重并看趋势；能量蛋白与摄入记录为后续版本） |
| **全程管理完整实现** | （当前只列出四类并标注「尚未提供」；毒性/并发症/带管/血管通路记录为后续版本） |
| **心理支持的量表分界** | （当前**可记录量表得分**并展示趋势，危机热线与求助资源已内置；官方分界标准核对后再呈现） |
| **量表题目内置** | 一期只做「得分录入」（版权考虑）；做题请用官方工具 |
| **在线试验数据源**（ChiCTR 在线 / ICTRP） | 一期只做本地归档导入 |
| **多语言（i18n）** | 一期纯中文 |
| **导出为 PDF** | 当前导出为可打印 HTML + Markdown |

> 完整路线图见 [](../)。

## 五、青囊能力相关

| 限制 | 说明 |
|---|---|
| 2 条通道需凭据 | 「高级医学证据」与「病友经验」需要你自己的凭据；未配置时**明示未启用**（不会拿别的通道凑）。已在「设置 → 检索通道（青囊 MCP）」提供填写入口，保存后立即生效 |
| 搜索可能需代理 | 国内访问境外站点通常需要代理；青囊会生成本机画像告诉你该填什么 |
| 分发包较大 | 青囊的离线依赖随包分发（约 40MB+），保证断网也能启动 |
| 青囊版本随发行版 | 青囊升级需随本发行版升级（快照方式） |

## 六、数据相关

| 限制 | 说明 |
|---|---|
| 不自动迁移官方版数据 | 与官方 DSH Desktop 数据目录不同；本期不提供自动迁移 |
| 备份需手动 | 见上文「功能完成度」 |
| 数据格式版本 | 当前为 v1；后续结构变更会提供自动迁移 |
| 卸载不删数据 | 数据在独立目录，卸载应用不影响数据（想彻底删除需手动删目录） |

## 七、已知的工程性限制

| 限制 | 说明 |
|---|---|
| 客户端无类型检查 | 宿主客户端形态是 `__ModuleLoader__` 单文件（零 import / 零构建），因此没有 tsc 覆盖；靠契约测试与人工走查保证 |
| 无法在 Linux 上端到端验证 | 开发机是 Linux，安装与打包验证在 CI 的目标平台进行 |
| 首次启动可能稍慢 | 青囊通道体检异步进行（不阻塞界面），但首启会比后续启动慢一点 |
| 诊断能力只到「本机」 | 事件时间线、诊断包、数据自检都只写本机；**没有**任何向开发者自动上报的通道（这是刻意的） |
| 事件时间线有上限 | 2000 条 / 2MB 滚动，超出后截断最旧 |
