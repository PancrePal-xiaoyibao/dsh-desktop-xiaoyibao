## 安装

### 装不上 / 提示「来自身份不明的开发者」

这是**未签名版本**的正常表现，不是故障。

**macOS**：
1. 打开「系统设置 → 隐私与安全性」
2. 在底部找到被拦截的提示，点「仍要打开」
3. 或者：右键点应用图标 → 「打开」→ 在弹窗里再点「打开」

**Windows**：
1. SmartScreen 提示「Windows 已保护你的电脑」
2. 点「更多信息」→「仍要运行」

> 为什么未签名：代码签名需要开发者证书（付费 + 实名）。社区版目前未购买，因此需要你手动放行一次。详见 [已知限制](KNOWN-LIMITATIONS.md)。

### 装完打开是空白的 / 打不开

1. 先确认系统版本满足要求（macOS 12+ / Windows 10+）
2. 如果之前装过，先完全退出旧版本（macOS 在程序坞右键退出；Windows 在任务管理器结束进程）
3. 还不行：删除应用后重新安装，**不要删数据目录**（数据在独立位置）

### 能和官方 DSH Desktop 同时装吗

**可以。** 两者的应用 ID 不同（`com.pancrepal.xyb.desktop` vs `io.dsh.desktop`），数据目录也互相独立，不会覆盖。

## 数据

### 我的数据存在哪

在你自己电脑上的**应用数据目录**（不是安装目录）。具体路径可在「设置」里看到。

详见 [隐私说明](PRIVACY.md)。

### 会上传到云端吗

**默认不会。** 只有两种情况会联网：

1. 你用青囊检索时（只传检索词）
2. 你**显式开启**云端解析后（只传你选中的那个文件）

详见 [隐私说明](PRIVACY.md)。

### 怎么备份

**当前方式**：手动把数据目录整体复制到另一个位置（如移动硬盘）。

> 一键备份功能在开发计划中。

### 换电脑怎么迁移

1. 旧机器：复制数据目录
2. 新机器：安装并**先启动一次**（让它创建目录）
3. 关闭软件，用旧机器的数据覆盖新机器的数据目录
4. 重新启动

### 卸载会删我的数据吗

**不会。** 数据在独立目录，卸载应用不影响数据。

⚠️ 注意：如果安装器问「是否删除用户数据」，**选择不删除**。

### 怎么彻底删除所有数据

手动删除数据目录（「设置」里可看到路径）。软件不会阻止你。

## 病历与解析

### 为什么导入的 PDF 读不出内容

**最常见原因：那是扫描件（图片型 PDF），没有文本层。**

本软件默认用「仅本地解析」，只能读**数字版 PDF**（有文本层的，比如医院系统导出的）。

**解决办法**：

1. **开启云端解析**（设置 → 文档解析 → 本地 + MinerU 云端解析）
   - 需要 MinerU API Token（免费额度足够个人使用）
   - 会先让你确认隐私条款（明确告诉你传什么、不传什么）
2. **或者手工录入**（核对界面可以手动填写）

### 扫描件/照片能识别吗

开启云端解析后可以。**但结果仍需要你逐项核对**——这是硬闸门，未核对的数据不会进趋势图。

### MinerU Token 怎么申请

1. 访问 MinerU 官网并注册 / 登录
2. 进入「API」→「API 管理」
3. 创建 Token 并复制
4. 回到本软件「设置 → 文档解析」，粘贴后点「校验并保存」

设置界面里也有「如何申请？」的入口。

### 我电脑里设了环境变量 MINERU_TOKEN，但界面里填的没用

这是**预期行为**：环境变量优先级更高。

界面会显示警告说明这一点。如果想用界面里填的，需要先移除环境变量。

### pipeline 和 vlm 模型选哪个

| 模型 | 特点 | 建议 |
|---|---|---|
| **pipeline**（默认） | **无幻觉**（有的就是有的，没有的不编） | **医疗场景推荐用这个** |
| vlm | 复杂版式更准，但极少数情况下可能生成原文没有的内容 | 病历场景不建议；若使用，**必须逐项核对**（界面会强制） |

### 解析结果和我看到的报告不一致

**核对界面就是为这个设计的。** 逐字段确认，不对就改。修改后会保留机器原始抽取值（可追溯）。

## 使用

### 为什么有些数据没出现在趋势图上

**因为它们还没被你核对确认。**

这是刻意设计的**人工闸门**：机器抽取的数据必须经你确认才能进入正式记录。未确认的数据不参与任何计算、不出现在图表上。

去「病情整理 → 报告核对」确认它们。

### 为什么颜色和箭头方向不一致

这是**刻意的**：**颜色由「指标方向」决定，不由「箭头方向」决定。**

- 白蛋白 ↑ = 绿色（上升是好事）
- CA19-9 ↑ = 红色（上升是坏事）

同样的箭头，相反的颜色。因为「变好还是变坏」取决于这个指标本身的含义。

### 为什么看板上有几项一直显示「未评估」

因为对应的功能模块还在开发中（临床匹配 / 心理支持 / 全程管理）。

界面会如实说明原因（如「未做匹配分析」「尚无不良反应记录」），**不会伪造数据**。

### 这个软件能告诉我该吃什么药吗

**不能，这是刻意的边界。**

本软件不做诊断、不给用药剂量、不推荐药物、不替代医生。涉及诊疗请以主治医生意见为准。

### 入排标准对照里显示「需医生评估」是什么意思

某些入组标准（如「预计生存期 ≥ 3 个月」「预计可完成 6 个周期随访」）**必须由研究医生评估**，患者自评没有意义。

本软件会把这类项**显式标注**出来，并且**不计入「符合」**，方便你整理成问题清单去问医生。

## 青囊能力

### 为什么搜不到内容

**先看本机画像里的「网络与代理」一节。**

在国内访问境外站点（PubMed、OpenAlex 等）通常需要代理。青囊会在首次启动时生成本机画像，里面有「建议使用的代理地址」。

**其他可能原因**：
- 网络暂时不可用 → 稍后重试
- 通道状态为「失败」→ 在「设置 → 青囊」点「重新体检」

### 为什么有两条通道显示「未配凭据」

「高级医学证据」（KnowS）与「病友经验」（得到笔记）需要你自己的凭据（向社区申请发放）。

**这是预期状态，不算故障**（界面用 ⬜ 标记而不是 ❌）。

- 「高级医学证据」缺凭据时会**自动降级到文献通道**，并明示降级事实
- 「病友经验」缺凭据时**明示未启用**（不会拿网页搜索冒充病友经验）

### 青囊的凭据（Key）在哪里填

「设置 → 检索通道（青囊 MCP）」里，每条需要凭据的通道都会列出**具体缺哪个 Key**，旁边就是输入框：

1. 把社区发给你的 Key 粘进输入框，点「保存」
2. 保存后立即按新凭据重建通道（不需要重启应用）
3. 状态会变成「已配置 · 来源 本机设置」；要撤销就点「清除」

界面只显示「配了没有 + 来自哪一层」，**永远不会把已保存的 Key 显示出来**。
若你更习惯用环境变量（如 `KNOWS_API_KEY`），环境变量优先，来源会显示为「环境变量」。

### 青囊是什么

青囊（QingNang）是社区维护的**医学能力资产包**，本发行版已内嵌并自动注册。

仓库：https://github.com/PancrePal-xiaoyibao/QingNang

### 青囊会不会上传我的病情

**不会。** 青囊的网络请求**只带检索词**，不带患者姓名、档案、记录或病历原文。这是代码层强制的（调用参数走白名单构造）。

## 其他

### 大模型 API Key 在哪里配置

「设置 → 模型与 API Key」会列出宿主里登记的所有模型提供方，每项显示**凭据名**与当前状态（已配置 / 未配置 / 来源），并给出输入框：

- 粘贴 Key → 保存：直接写入**宿主自己的凭据存储**（与宿主设置面板是同一份），本工作台不留副本
- 已配置的项右侧有「清除」，可撤销
- 界面上**只显示状态，不显示已保存的值**

一句话解释为什么这样设计：两处各存一份 Key 必然互相覆盖，所以这里只是宿主凭据的入口，不是第二份存储。

### 为什么没有自动更新

本期关闭了自动更新（不指向官方更新源，避免版本冲突）。升级请手动下载新版本安装包覆盖安装。

### 升级会丢数据吗

**不会。** 数据在独立目录，不在应用安装目录里。

但**建议升级前先备份**（手动复制数据目录）。
