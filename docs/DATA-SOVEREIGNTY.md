# 数据主权说明

> 一句话：**你的数据是你的。** 没有账号、没有云端、没有厂商能访问。

---

## 一、数据主权归你

| 项 | 说明 |
|---|---|
| 存储位置 | 你自己的电脑（应用数据目录） |
| 所有权 | 归你 |
| 访问控制 | 只有你能访问（文件系统权限） |
| 厂商访问 | **不可能**——数据从不离开本机（除你显式开启的云端解析） |
| 删除 | 你随时可删（删文件即删数据） |
| 导出 | 数据是开放格式（JSON / JSONL / 原始 PDF），不锁定 |

---

## 二、没有账号体系

| 项 | 说明 |
|---|---|
| 登录 | **无** |
| 注册 | **无** |
| 云端同步 | **无** |
| 多设备同步 | **无**（换设备靠备份/手动迁移） |
| 遥测 | **无**（`telemetry_allowed_values: ["off"]`） |

**为什么不做账号**：账号意味着数据要离开本机、要有服务端、要有合规责任。医疗数据的这些成本远高于收益。本产品的选择是「数据主权优先」。

---

## 三、数据格式（开放、不锁定）

| 数据 | 格式 | 说明 |
|---|---|---|
| 患者档案 | JSON | 纯文本，可读可编辑 |
| 记录流（指标 / 用药 / 评估 / 全程管理） | JSONL（每行一条 JSON） | 追加式，可 diff、可脚本处理 |
| 病历原件 | 原始格式（PDF / JPG 等） | **只增不改**，永不转换 |
| 派生数据 | JSON | 可重建（删了重新解析即可） |
| 设置 | JSON | 纯文本 |

**没有任何专有格式。** 你可以用任何文本编辑器打开，可以用脚本处理，可以导入其他工具。

---

## 四、备份与迁移

### 备份

**一期方式**：手动复制数据目录（「设置」里可看到路径）。

> 一键备份与还原在开发计划中。当前建议：定期把数据目录整体复制到另一个位置（如移动硬盘、你自己的加密盘）。

**备份包含什么**：
- 患者档案、全部记录流、病历原件、派生数据、设置

**备份不包含什么**：
- MinerU Token（安全考虑；还原后需重新配置）
- 青囊的 `~/.qingnang/private/`（独立目录，需单独备份）

### 迁移（换电脑）

1. 在旧机器上复制数据目录
2. 在新机器上安装本软件，**先启动一次**（让它创建数据目录）
3. 关闭软件，用旧机器的数据覆盖新机器的数据目录
4. 重新启动

### 与官方 DSH Desktop 的关系

| 项 | 说明 |
|---|---|
| 应用 ID | 不同（`com.pancrepal.xyb.desktop` vs `io.dsh.desktop`） |
| 数据目录 | **不同**（互不干扰） |
| 可否共存 | **可以**（同时装两个不会互相覆盖） |
| 数据互通 | **不互通**（本期不提供自动迁移） |

## 五、卸载会怎样

| 项 | 说明 |
|---|---|
| 卸载应用 | **不会**删除你的数据（数据在独立目录） |
| 数据仍在 | 是；重新安装后仍可访问 |
| 想彻底删除 | 手动删除数据目录（「设置」里可看到路径） |

> ⚠️ 注意：卸载时如果安装器问「是否删除用户数据」，**选择不删除**。不同平台表现不同，请留意。

## 六、青囊数据的边界

青囊有自己独立的私有目录 `~/.qingnang/private/`（权限 0700）：

| 项 | 说明 |
|---|---|
| 存什么 | 青囊相关的私有内容（如你自己的笔记） |
| 与业务数据的关系 | **相互独立**（`~/.qingnang/private/` vs 应用数据目录的 `xyb/`） |
| 是否进备份 | **不进**（青囊资产是程序的一部分，不是本产品的用户数据） |
| 是否上传 | **不上传**（青囊隐私铁律） |

---

## 七、你的权利

| 权利 | 怎么行使 |
|---|---|
| 查看自己的全部数据 | 打开数据目录 |
| 导出 | 复制文件 / 用脚本处理（开放格式） |
| 删除 | 删文件（应用不物理阻止） |
| 迁移 | 复制数据目录 |
| 不使用云端功能 | 保持「仅本地解析」（默认） |
