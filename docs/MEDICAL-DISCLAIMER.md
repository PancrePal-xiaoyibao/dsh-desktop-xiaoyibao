## 一、六条红线

本软件在任何情况下都遵守以下六条红线：

| 编号 | 红线 | 具体含义 |
|---|---|---|
| **M-1** | **不做诊断** | 不判断你得了什么病、处于什么阶段、指标异常意味着什么 |
| **M-2** | **不做处方** | 不推荐药物、不给剂量、不建议治疗方案调整、不提及任何药名 |
| **M-3** | **不解读量表** | 心理量表只按各量表官方分界呈现档位，不解释分数含义 |
| **M-4** | **不替医生判定** | 需要医生评估的项（如「预计生存期 ≥ 3 个月」）只标注、不判定 |
| **M-5** | **危机必须兜底** | 心理支持每页常驻危机热线，并明确声明不提供危机干预 |
| **M-6** | **一切可溯源** | 每个结论都能点开看到依据；不存在「无依据的黑盒结论」 |

## 二、各场景声明（与代码一致）

### 2.1 数值解释场景（指标、卡片、营养）

> **以上为数值描述与常见原因，不构成诊断。具体含义请以医生解释为准。**

适用位置：指标趋势、营养卡片、看板维度说明。

### 2.2 分子 / 名词科普场景（基因、IHC）

> **以上为通行教科书级描述，用于帮助你理解报告中的名词。不构成诊断或治疗建议，具体含义请以医生解释为准。**

适用位置：基因科普弹窗、分子分型卡片说明。

### 2.3 量表场景（心理自评）

> **分数按各量表官方分界呈现，工作台不做解读。**

适用位置：情绪自评页、量表历史曲线。

### 2.4 危机场景（心理支持每页常驻）

> **工作台不能提供危机干预，以上为公共服务信息。**

适用位置：心理支持模块的每个子页底部（无条件显示）。

**同时提供**：
- 全国统一心理援助热线 `12356`（24 小时）
- 希望24热线 `400-161-9995`
- 紧急情况 `120`

### 2.5 临床匹配场景

> **匹配结论不构成入组资格判定，需医生评估的项由研究医生判定。**

适用位置：匹配分析页、匹配结论导出物。

### 2.6 营养目标场景

> **以上为按体重与常见系数计算的目标区间，不构成营养处方。具体摄入方案请以医生或临床营养师的意见为准。**

适用位置：营养管理页、能量与蛋白目标卡片。

### 2.7 全程管理场景

> **以上为记录与事实呈现，不构成医疗建议。如需判断请联系医生。**

适用位置：毒性 / 并发症 / 带管 / 血管通路记录页。

### 2.8 数据主权场景

> **数据默认保存在本机。仅在你自己开启云端解析时，所选文件会上传解析；档案、记录、笔记与密钥不上传。**

适用位置：设置页、隐私说明。

## 三、明确不做的事

| ❌ 不做 | 说明 |
|---|---|
| 诊断疾病 | 不判断病种、分期、病情严重程度 |
| 推荐药物 | 不出现任何药名 |
| 给用药剂量 | 一句也不给，一律引导问主治医生 |
| 解读量表 | 只呈现官方分界，不解释含义 |
| 判断入组资格 | 只把入组标准逐条对照给你看 |
| 替医生判定 | 需医生评估的项只标注 |
| 危机干预 | 只提供热线信息，明确声明不提供干预 |
| 风险评估算法 | 不做「高危 / 低危」判断 |
| 自动提醒推送 | 一期不做（不催你复查、不催你维护管路） |

## 四、遇到这些情况请立即就医

**不要依赖任何 AI 工具。**

- 剧烈腹痛
- 黄疸加重
- 呕血 / 黑便
- 持续高热
- 意识改变
- 呼吸困难
- 出现伤害自己的想法

## 五、关于「需医生判定」的项

某些入组标准（如「预计生存期 ≥ 3 个月」「预计可完成 6 个周期随访」）**必须由研究医生评估**，患者自评没有意义。

本软件的处理方式：

1. 把这类标准**显式标注**为「需医生评估」/「此项需研究医生评估」
2. **不计入「符合」的统计**
3. 在界面上**成组醒目呈现**（方便你整理成问题清单去问医生）

**软件不会替医生做这个判断。**

## 六、关于数据准确性

| 项 | 说明 |
|---|---|
| 机器抽取的数据 | **必须经你人工核对**才能进入趋势图与看板 |
| 未核对的数据 | 不参与任何计算、不出现在图表上 |
| 解析模型 | 默认用「无幻觉」的 pipeline 模型；选 vlm 时强制逐字段核对 |
| 数据来源 | 每条记录可溯源到来源文档与页码 |

**为什么这么做**：错误的医疗数据比没有数据更危险。因此本软件把「人工确认」做成硬闸门，而不是可选项。
