# 隐私说明

> 本文件回答三个问题：**数据在哪 / 何时联网 / 联网传什么**。
> 这三问是隐私说明的最低要求，缺一不可。
>
> ⚠️ **本软件是社区发行版，非 DeepSeek 官方产品**，与 DSH Desktop 官方团队无隶属关系。

---

## 一、数据在哪

**默认完全保存在你自己的电脑上。**

| 数据 | 位置 | 权限 |
|---|---|---|
| 患者档案（姓名、性别、出生年、确诊日期） | 应用数据目录 `xyb/patients/<患者id>/profile.json` | 仅当前用户可读写 |
| 指标记录（化验数值、核对状态、来源） | 同上 `records.jsonl` | 同上 |
| 用药记录 | 同上 `medications.jsonl` | 同上 |
| 评估记录（情绪量表得分） | 同上 `assessments.jsonl` | 同上 |
| 全程管理记录（毒性、并发症、管路、通路） | 同上 `cares.jsonl` | 同上 |
| **病历原件**（你导入的 PDF / 照片） | 同上 `documents/` | 同上 |
| 解析派生数据（可重建） | 同上 `derived/` | 同上 |
| 全局设置（解析模式、模型选择） | 同上 `settings.json` | 同上 |
| 青囊私有数据（你的笔记等） | `~/.qingnang/private/` | **0700** |
| MinerU Token（若配置） | `~/.mineru/config.yaml` | 与 MinerU 命令行共用 |

**应用数据目录的具体路径**：可在「设置」里看到（不同平台不同，通常在用户目录下的应用数据区）。

**无账号、无云同步。** 本软件没有登录，不会把你的数据上传到任何服务器。

## 二、何时联网

**只有两种情况会联网**，其余时候程序不发起任何网络请求。

> ⚠️ **本发行版额外关闭了「故障报告上传」**：社区版不向任何官方端点发送故障报告。
> 诊断信息只写在本机（见下文「本机诊断」一节）。

### 情况 1：你使用青囊检索能力时

青囊提供 5 条免凭据检索通道（网页搜索 / 中文搜索 / PubMed / OpenAlex / 临床试验）。当你（或 AI 助手）用这些能力查资料时，会向对应的公开服务发起请求。

### 情况 2：你**显式开启**云端解析后

默认是「仅本地解析」。如果你主动开启「本地 + MinerU 云端解析」并**通过隐私确认闸门**，扫描件与照片会上传解析。

**未通过隐私确认闸门时，程序不会发起任何云端请求**（这是代码层强制的，不是界面隐藏）。

## 二·五、本机诊断（不联网）

社区版内置三项**只写本机**的诊断能力，用来帮助排障；它们不会上传任何内容：

| 能力 | 写在哪 | 内容边界 |
|---|---|---|
| 事件时间线 | 数据目录 `events/events.jsonl` | 只记「启动 / 建档 / 核对 / 失败」这类事件，且**过脱敏器**（路径、长数字、手机号、URL、已知姓名一律替换）；上限 2000 条 / 2MB |
| 诊断包导出 | 数据目录 `diagnostics/` | 只含版本、运行环境、路由名、目录**结构统计**（没有文件名）与已脱敏事件；**绝不**含病历正文、姓名、原始文档名、绝对路径 |
| 数据自检与修复 | 数据目录（含 `.backup-`） | 检查可写性 / JSON 可解析 / 坏行 / 临时残留 / 备份可用 / 磁盘余量；修复前**先整根备份** |

导出的诊断包是否交给他人**由你自己决定**（包内附隐私声明，写明哪些内容永不写入）。

## 三、联网传什么

### 青囊检索

| 项 | 内容 |
|---|---|
| **传什么** | **只有检索词**（如疾病名、靶点、药物名、试验编号） |
| **不传什么** | 患者姓名、档案、指标记录、病历原文、笔记、Token |
| **为什么** | 检索只需要关键词；传更多既无必要也不安全 |
| **技术保证** | 调用参数走**白名单构造**（只含检索词字段），有自动化断言 |

### MinerU 云端解析

| 项 | 内容 |
|---|---|
| **传什么** | **仅你所选的那个文件本身** |
| **不传什么** | 患者档案、基因结果、治疗记录、收藏与笔记、其他文件 |
| **处理方式** | 服务端解析完成后不保留 |
| **可随时关闭** | 是；关闭后立即生效，不再发起请求 |
| **隐私政策** | 见 MinerU 官网（界面上有入口） |
| **技术保证** | 上传请求体走**白名单构造**（只含 `file` / `name` / `model` 三个字段），有键集合断言 |

## 四、凭据安全

| 项 | 做法 |
|---|---|
| MinerU Token 读取优先级 | ① 环境变量 `MINERU_TOKEN` ② `~/.mineru/config.yaml` ③ 应用内设置 |
| 界面展示 | 只显示 `sk-` + 遮罩 + 尾 4 位 |
| 日志 | **绝不记录 Token 全文**（有自动化审计） |
| 备份包 | **不包含 Token**（还原后需重新配置） |
| 导出物 | 不包含 Token |
| 环境变量优先时的行为 | **不覆盖**环境变量，且界面明确提示「此处填写不生效」 |

## 五、不会做的事

| ❌ 不做 | 说明 |
|---|---|
| 不上传你的病情数据 | 无账号、无云同步、无遥测 |
| 不把病历交给第三方云盘 | 不做第三方云盘集成 |
| 不读取青囊 `private/` 之外的用户数据副本 | 青囊数据边界明确 |
| 不在日志里写病历正文 | 日志只记阶段与错误码 |
| 不把真实患者信息放进仓库 | 示例数据全部为明显虚构 |

## 六、你可以怎么验证

| 想验证 | 怎么做 |
|---|---|
| 是否真的不联网 | 断网后使用（除云端解析外，功能应正常） |
| 数据存在哪 | 「设置」里看数据目录路径；到文件管理器确认 |
| Token 是否安全 | 看界面是否只显示遮罩；查看日志目录（应无 Token 全文） |
| 上传了什么 | 开启云端解析前会显示将上传哪些文件；实际请求体只含文件本身 |
